# 称号投票アプリ（Cloudflare Workers版）

10/24 合同卒業制作お披露目会用。URLを開くだけで誰でも投票できます（ログイン不要）。

| 画面 | URL | 使う人 |
|---|---|---|
| 参加者 | `https://<デプロイ先>/` | 受講生（Zoomチャットに貼る） |
| 運営 | `https://<デプロイ先>/admin` | 運営（合言葉が必要） |
| 表示 | `https://<デプロイ先>/stage` | 画面共有するPC |

## デプロイ（初回）

Node.js 18以上が入ったPCで、このフォルダを開いて:

```bash
npm install
npx wrangler login                 # ブラウザでCloudflareにログイン
npx wrangler secret put ADMIN_PIN  # 運営画面の合言葉を入力（初回はWorker作成の確認が出たらY）
npx wrangler deploy
```

最後に `https://shougou-app.<アカウント名>.workers.dev` が表示されます。それが参加者用URLです。

- 合言葉を変えたいときは `npx wrangler secret put ADMIN_PIN` をもう一度。
- Worker名を変えたいときは `wrangler.jsonc` の `"name"` を書き換えてからデプロイ。
- 無料プランで動きます（Durable Objects の SQLite 版を使用）。

## ローカルで試す

```bash
npm install
npx wrangler dev   # http://localhost:8787 。運営の合言葉は .dev.vars の 31
```

## 本番までにやること

1. **運営画面 → 語彙タブ**で語彙を確定（保存するとそれまでの票は消えるので本番前に）
2. **運営画面 → 登壇者タブ**にリストを貼り付け → 「発表順をシャッフル」
   - 1行1人：`名前,クラス,プロダクト名,写真URL`（スプレッドシートからのタブ区切り貼り付けもOK）
3. 顔写真は写真URLの列か、進行タブの「顔写真URL」で登壇者ごとに設定
4. リハーサル後、**登壇者タブ →「票と称号をすべて消す」**

## 当日の進行

発表 → 参加者が投票 → 運営「投票を締め切る」→（必要なら称号を選び直し）→「称号を表示する」→ 表示画面で演出 →「次の登壇者へ」

- 参加者には票数は見えません。運営画面だけに出ます。
- 同じ端末・同じブラウザからの投票は1人1票（選び直しは上書き）。シークレットウィンドウや別ブラウザなら別人扱いになります。
- 表示画面を開き直したときは演出なしで現在の状態が出ます。「称号をもう一度表示」で演出を再生できます。
